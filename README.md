# Fruti games

The games for the [Fruti launcher](https://jogresh7-ship-it.github.io/fruti-emulr/) (site code: `fruti-emulr`).
The launcher reads this repo first, then any games still in `fruti-emulr/rom/`.

```
rom/<Console>/<Game Name>/<game file or parts>
rom/<Console>/<Game Name>/cover.jpg   (optional)
```

Each console folder has a README with its details. The easiest way to add a game is the launcher's
**Import → Upload to GitHub** (owner only): it checks the file, cuts it into 25 MB parts and uploads it here.

**Actions:** *Make big PSP games playable (.cso)* turns big zipped PSP games, and every zipped PS2 game,
into parts the browser can play. The launcher starts it by itself after an upload that needs it.

Anything in this public repo can be downloaded by anyone.
